Phase 3 · Pace Work
Weeks 12–15
Replace one easy run with a structured session each week. One long run stays easy (Zone 2). One easy run stays easy. Tempo = comfortably hard, Zone 3. Intervals = hard, Zone 4.

How to run intervals (weeks 14–15)
Warmup
Run 1 mile easy (Zone 2) before starting any hard effort. Do not skip this.
Hard rep
Run for 1 minute at Zone 4 — hard but controlled. Not a sprint. You should feel like you could hold this for 3–4 minutes if you had to, but you're pushing.
Recovery
Walk or slow jog for 2 min (week 14) or 90 sec (week 15). Full recovery before the next rep. Don't rush this.
Repeat
6 times (week 14) or 8 times (week 15). If the last few reps feel impossible, you went out too hard on the first ones. Start conservative.
Cooldown
Run 1 mile easy (Zone 2) after your last rep. Never stop cold after hard running.
